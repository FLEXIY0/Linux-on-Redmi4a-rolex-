# Установка postmarketOS на Redmi 4A с Windows — полная инструкция

От чистого телефона на MIUI до работающего postmarketOS с IceWM.

## Что понадобится

- ПК с Windows 10/11
- USB-кабель (нормальный, не «только зарядка»)
- Телефон Xiaomi Redmi 4A (rolex), желательно заряженный >50%
- ~2 ГБ свободного места на диске

## Шаг 0. Разблокировка загрузчика (если ещё не разблокирован)

⚠️ Разблокировка **стирает все данные** на телефоне. Сделай бэкап.

1. На телефоне: **Настройки → О телефоне** → тапни 7 раз по «Версия MIUI» —
   включатся «Для разработчиков».
2. **Настройки → Расширенные настройки → Для разработчиков**: включи
   **«Заводская разблокировка» (OEM unlocking)** и **«Отладка по USB»**.
3. Там же открой **«Статус Mi Unlock»** и привяжи телефон к своему Mi-аккаунту
   (телефон должен быть в него залогинен, SIM с интернетом вставлена).
4. На ПК скачай **Mi Unlock Tool**: https://en.miui.com/unlock/ — залогинься
   тем же Mi-аккаунтом.
5. Выключи телефон, зажми **Громкость-вниз + Питание** — попадёшь в fastboot
   (заяц в шапке-ушанке). Подключи к ПК и жми Unlock в программе.
6. Xiaomi может заставить ждать (обычно 72 часа – 30 дней с момента привязки).
   После ожидания повтори — телефон разблокируется и сбросится.

Если загрузчик уже разблокирован — пропусти этот шаг.

## Шаг 1. Установи инструменты на ПК

1. **platform-tools (adb/fastboot)**:
   скачай https://dl.google.com/android/repository/platform-tools-latest-windows.zip
   и распакуй, например в `C:\platform-tools`.
2. **7-Zip** (чтобы распаковать .xz): https://www.7-zip.org/
3. Драйверы: на Windows 10/11 обычно ставятся сами. Если в шаге 3 телефон
   не увидится — поставь «Xiaomi USB Driver» (или Google USB Driver) и проверь
   в Диспетчере устройств, что телефон определился как **Android Bootloader
   Interface**, а не как неизвестное устройство.

## Шаг 2. Скачай образы

Со страницы релиза
https://github.com/FLEXIY0/Linux-on-Redmi4a-rolex-/releases/tag/v1.0 :

- `postmarketos-redmi4a-rolex-icewm.img.xz`
- `lk2nd.img`

Распакуй `.img.xz` 7-Zip'ом (ПКМ → 7-Zip → Распаковать здесь) — получится
`postmarketos-redmi4a-rolex-icewm.img` (~1.4 ГБ). Положи оба файла в
`C:\platform-tools`, чтобы не возиться с путями.

## Шаг 3. Прошей загрузчик lk2nd

1. Выключи телефон. Зажми **Громкость-вниз + Питание** до появления fastboot.
2. Подключи телефон к ПК.
3. Открой PowerShell: в Проводнике зайди в `C:\platform-tools`,
   Shift + ПКМ по пустому месту → «Открыть окно PowerShell здесь».
4. Проверь связь:
   ```powershell
   .\fastboot devices
   ```
   Должен показаться серийник. Если пусто — проблема с драйвером (см. шаг 1).
5. Прошей и перезагрузись:
   ```powershell
   .\fastboot flash boot lk2nd.img
   .\fastboot reboot
   ```
6. **Сразу зажми Громкость-вниз** и держи, пока не появится меню lk2nd.
   Телефон снова определится как fastboot-устройство — это уже fastboot
   самого lk2nd (проверь: `.\fastboot devices`).

## Шаг 4. Прошей postmarketOS

В fastboot'е lk2nd (шаг 3.6):

```powershell
.\fastboot flash userdata postmarketos-redmi4a-rolex-icewm.img
.\fastboot reboot
```

Заливка идёт несколько минут — не трогай кабель. Отдельный boot.img не нужен:
образ содержит разделы pmOS_boot/pmOS_root, ядро lk2nd грузит сам через extlinux.

После перезагрузки (снова держать ничего не надо — lk2nd сам загрузит систему)
появится postmarketOS.

## Шаг 5. Первый запуск

- Логин: `user`
- Пароль: `postmarketos`

Запуск IceWM после входа в консоль:

```sh
echo "exec icewm-session" > ~/.xinitrc
startx
```

## Если экран не завёлся — SSH через USB

Телефон при подключении по USB поднимает сеть (RNDIS): в Windows появится
новый сетевой адаптер. В PowerShell:

```powershell
ssh user@172.16.42.1
```

(пароль `postmarketos`; клиент OpenSSH встроен в Windows 10/11).
Если адаптер не появился — Диспетчер устройств → обнови драйвер →
«USB RNDIS Adapter».

## Полезное

- Меню lk2nd (выбор загрузки): держать **Громкость-вниз** при включении.
- Обычный fastboot Xiaomi (для отката): lk2nd → пункт Reboot to bootloader,
  либо прошей обратно стоковый boot.img.
- Вернуться на MIUI: прошить сток-прошивку через Mi Flash Tool.
- Wi-Fi/модем на mainline-ядре msm8917 могут работать нестабильно — это
  особенность порта, не ошибка прошивки.
